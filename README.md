# 두 명의 명리학자가 바라본 나

생년월일·출생시간·양력/음력·성별·출생지역·현재 고민을 입력하면 사주 명식을 계산하고, 서로 다른 관점의 두 명리 해석을 A4 세로 1장으로 구성하는 정적 웹사이트입니다.

## 주요 기능
- 양력 및 한국 음력 입력, 윤달 지원
- 출생시간 미상 시 시주 제외
- 년주·월주·일주·시주 및 오행·십성·합충 기반 요약
- 전문가 A: 직설적인 현실파
- 전문가 B: 월령·오행·십성·합충을 종합하는 신중한 정통파
- 현재 고민에 맞춘 조언
- A4 1장 인쇄/PDF 저장 CSS
- 아이보리·먹색·버건디·금색 기반 인쇄용 디자인

## 기술
별도 빌드 없이 `index.html` 하나로 동작합니다.

- `korean-lunar-calendar@0.4.0`: 한국 음력 → 양력 변환
- `lunar-javascript@1.7.7`: 절기 기준 사주 팔자 계산
- HTML / CSS / JavaScript

> 해석은 전통 명리 규칙을 구조화한 참고용 콘텐츠이며 확정된 미래를 의미하지 않습니다. 시주는 입력한 표준시 기준이며 진태양시 보정은 적용하지 않습니다.

## GitHub Pages
`Settings → Pages → Deploy from a branch → main / (root)`로 설정하면 배포할 수 있습니다.
